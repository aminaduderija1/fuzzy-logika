# Fuzzy Logic Credit Rating System

Sistem za procjenu kreditnog rejtinga i evaluaciju rizika implementiran u Pythonu primjenom teorije neizrazite (fuzzy) logike.

## Tehnologije i biblioteke
* Python 3
* scikit-fuzzy
* NumPy
* Matplotlib

## Opis projekta
Sistem analizira više ulaznih parametara (poput prihoda, zaposlenja i postojeće zaduženosti) te kroz definisani skup fuzzy funkcija pripadnosti i pravila rezonovanja izračunava konačnu ocjenu kreditne sposobnosti korisnika.
